# Go Learning

个人 Go 语言学习项目记录，涵盖各种技术和框架的实践示例。

## 项目列表

| 目录 | 内容 |
|------|------|
| `go-ai/` | OpenAI API 调用示例 |
| `go-crawler/` | 爬虫相关（Colly 框架 + Python 版） |
| `go-docker/` | Docker 学习笔记 |
| `go-kafka/` | Kafka 学习（四个阶段：创建主题 → 生产消费 → 消费者组 → 批量压缩） |
| `go-kratos/` | Kratos 微服务框架示例 |
| `go-redis/` | Redis 操作（含 Cache-Aside 模式） |
| `go-resty/` | HTTP 客户端 resty 使用 |
| `go-wire/` | Google Wire 依赖注入 |
| `go-zero/` | go-zero 框架（用户 API、商城 RPC） |
| `grpc-learn/` | gRPC 学习（含流式传输） |
| `lua/` | Lua 脚本学习 |
| `minio/` | MinIO 对象存储 |
| `py-Vs-go/` | Python vs Go 对比 (已迁移)|
